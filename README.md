1. Thông tin bài tập

Môn học: Node.js

Bài: Bai03 - Bt01

Nội dung: Xây dựng class SinhVien và lọc danh sách sinh viên.

2. Nội dung thực hiện

Khai báo class SinhVien gồm các thuộc tính: mã sinh viên, họ tên, tuổi và điểm.

Tạo danh sách gồm 5 sinh viên.

Sử dụng hàm filter() kết hợp Arrow Function để lọc sinh viên có điểm từ 5 trở lên.

Sử dụng console.log() để hiển thị kết quả.

3. Cấu trúc thư mục

Bt01/
├── BT01.js
├── README.md

4. Các bước thực hiện

Bước 1: Mở Visual Studio Code và mở thư mục Bt01.

Bước 2: Tạo file BT01.js và nhập mã nguồn chương trình.

Bước 3: Mở Terminal trong Visual Studio Code.

Bước 4: Chạy chương trình bằng lệnh: cd Bai03 sau đó nhập lệnh: node BT01.js

Bước 5: Kiểm tra kết quả hiển thị trên Terminal.

5. Kết quả chương trình

Chương trình lọc được 3 sinh viên có điểm từ 5 trở lên:

SV01 - Nguyễn Anh Quân - 8 điểm.

SV03 - Nguyễn Đức Cường - 7 điểm.

SV04 - Trương Thị Hồng - 5 điểm.
